## Decisions made mid-milestone (beyond the approved plan)

- Feed (Localist) events commit directly with automated gates; the per-user staged-review
  pattern is reserved for contributions. `useStagedIngest` was never built (no consumer).
- Localist fetch: Cloudflare challenges non-browser TLS **probabilistically** — server fetch
  first, browser relay fallback, relayed payloads host-validated. CSP `connect-src` widened to
  `https://*.edu https://*.localist.com`; also fixed a pre-existing CSP bug blocking Google
  Fonts in production.
- Enrichment runs client-side (user's BYOK key via `lib/ai.js`); server validates + writes.
- All-day calendar blocks default **soft** in the conflict engine (timed = hard).
- Share threshold for contributions: confidence ≥ 0.8. Shared rows never user-deletable.
- Dedicated Recruiting calendar via `calendar.app.created` + one-time re-consent; lives on
  the personal slot by default, user-switchable (Settings).
- `migration-test-e2e@test.dev` (test account) was given `school_id = umich` for browser
  testing; harmless.
