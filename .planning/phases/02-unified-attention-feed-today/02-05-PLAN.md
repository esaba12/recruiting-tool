<objective>
Close the one confirmed BLOCKER gap from 02-VERIFICATION.md (Truth 1 / ATTN-01, corroborated by 02-REVIEW.md's CR-01): `TodayTab.jsx`'s page-level "all clear" gate (`allEmpty`) decides whether to render the unified attention feed or the collapsed `<EmptyState>` using `timelineFindsCount` — a piece of React state that starts at a hardcoded `0` and is only ever corrected by `TimelineFindsPanel`'s `onPendingChange` callback, which doesn't fire until *after* `TimelineFindsPanel` mounts at line 445 — well past the `allEmpty` early-return at line 381. When the other 8 `lib/attention.js`-derived arrays are all empty (an ordinary, common state), Today permanently shows "Nothing needs your attention" even when real pending Timeline Finds items sit in `localStorage`'s `rec_timeline_pending`, because the one component capable of ever correcting the count never gets a chance to mount.

The fix (Approach (a) from both 02-VERIFICATION.md's `missing` list and 02-REVIEW.md's CR-01 proposed fix, and the one that matches `app/src/.../02-UI-SPEC.md:142`'s literal contract — "if **all 9** arrays are empty, render one page-level EmptyState in place of the stack" — treating Timeline Finds symmetrically with the other 8 categories): initialize `timelineFindsCount` synchronously from `localStorage` via a lazy `useState` initializer, exactly mirroring `TimelineFindsPanel.jsx`'s own `pending` state's synchronous-from-storage init pattern (`useState(() => lsGet(PENDING_KEY) || [])`). This makes the gate correct on the very first render, with no dependency on mount order. Approach (b) (always-mount `TimelineFindsPanel`, rescope `allEmpty` to the other 8) was considered and rejected — it would render the full section stack (not the page-level EmptyState) even when Timeline Finds is the *only* non-empty category and simultaneously has zero pending items, contradicting the UI-SPEC's "in place of the stack" / "all 9 arrays" framing, and it changes visual behavior beyond what's needed to close this gap.

Purpose: closes Success Criterion 1 / ATTN-01, the only requirement 02-VERIFICATION.md scored as failing (2/3 must-haves) for Phase 2.
Output: `app/src/components/TimelineFindsPanel.jsx` (one-line export addition, zero behavior change), `app/src/components/TodayTab.jsx` (corrected `timelineFindsCount` initial state + updated code comment, `allEmpty`/early-return/mount logic otherwise byte-identical).
</objective>
